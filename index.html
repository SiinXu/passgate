Why now

01

Reset tickets are silent burn

Every password reset costs support time and some users never come back. Passkeys turn the loop into one device prompt.

02

Phishing-resistant by design

WebAuthn binds each credential to your RP ID, so a look-alike domain cannot use it. Stolen passwords stop being the default way in.

03

OS-level UX users already know

iOS, Android, Windows and macOS already prompt for Face ID, fingerprint, PIN or a security key. Your users have seen it before.

FAQ

Is this a security audit?

No. PassGate is implementation help and a template. It does not certify your product. Responsibility boundaries are written into the order.

What if my repo access is delayed?

The 48h clock starts when we have agreed access and a signed-off stack questionnaire. Waiting time is marked on the ticket.

Do you handle Safari autofill quirks?

Yes, within the web browser matrix in TEST_PLAN. Native app SDKs are out of scope.

Can I upgrade from template to install?

Yes. Template buyers can book an install. The $49 is not deducted unless a promotion says so.

Refunds?

Template: digital goods, refunded only if the ZIP fails to download within 24h and we cannot fix it. Install: if we miss the 48h window for reasons on our side, 50% of the install fee is refunded.
